## What M7D8 proves

M7D8 closes the ordering boundary after M7D7 atomic promotion:

```text
verified candidate
→ M7D7 atomic canonical authority transaction
→ promoted
→ M7D8 cursor/schedule/control metadata commit
```

The scheduler no longer advances authoritative schedule state merely because a due job was created. The exact due slot is persisted as immutable run metadata in `tenant_import_jobs.sync_scheduled_for`.

A bounded finalization runner now:

1. discovers only exact incremental jobs in `finalizing/finalize`;
2. acquires a phase-aware control-plane lease with compare-and-set semantics;
3. resolves the exact tenant/source/import/data-plane context;
4. invokes the already-proven M7D7 promotion primitive;
5. commits schedule + terminal control metadata only after durable promotion success;
6. treats an exact already-`promoted` run as valid crash replay and commits only the remaining control metadata;
7. fails closed on stale schedule/run ownership;
8. makes duplicate terminal finalization a no-op.
