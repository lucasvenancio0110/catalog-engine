## What M7D9 proves

M7D9 closes authoritative repeated-miss removal while preserving Last Known Good and merchant truth.

The effective state model is scoped:

```text
observed in healthy promoted scope
→ active / miss_count = 0

first independent authoritative miss
→ missing / miss_count = 1

second independent authoritative miss
→ missing / miss_count = 2

threshold authoritative miss
→ scope detached
→ remove canonical product only if no other valid scope still owns it

later authoritative observation
→ RESTORED
→ active / miss_count = 0
→ restore retained merchant override truth
```

Only complete, healthy, plausible and safety-authorized promoted runs may progress absence. Partial/incomplete scans, provider failure, malformed/pagination failure, zero results and catastrophic volume collapse preserve LKG and cannot advance destructive miss state.

Replay of the same promoted run is idempotent and cannot increment miss count twice.

A product with multiple source scopes survives detachment from one scope while another valid scope remains. Canonical deletion happens only after the last valid scope detaches at threshold.

## Merchant override retention

Before final canonical deletion, a durable merchant classification override is copied to retention storage that has no `ON DELETE CASCADE` dependency on the canonical product.

On `RESTORED`, the product returns through the verified candidate/promotion path and retained override truth is reapplied. Retention cleanup happens only after restoration has safely re-established the live override.

This closes the D7 fail-closed `sync_promotion_removal_not_ready` boundary for valid schema-v8 removal candidates without allowing product deletion to erase merchant decisions.
