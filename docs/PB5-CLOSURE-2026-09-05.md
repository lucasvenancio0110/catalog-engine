## Important PB6 handoff finding

Live-code audit before PB6 found that source connection currently unlocks the automated provisioning chain, and automatic initial-import discovery is enabled globally. PB6 therefore must not be implemented as a cosmetic selector.

PB6 must make the merchant's import scope/decision a real server-side authority that the initial-import dispatcher actually honors. If provider-safe scope discovery cannot expose stable merchant-safe choices without raw supplier identifiers, the approved beta fallback is an explicit **full-catalog** decision.

The safe PB6 design must preserve already-running/previously-completed import evidence and must not destructively reset a tenant merely to introduce the new decision gate.

## Rollback boundary

If new source connection becomes unhealthy, disable new merchant source mutations/UI while preserving existing private connected-source state. Do not expose private locators or fall back to an unauthenticated/default-tenant path.
