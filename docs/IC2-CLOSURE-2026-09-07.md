## Defects found during proof and fixes

Production proof work found infrastructure/proof-path defects rather than hiding them:

1. shared `catalog-engine-production-d1` concurrency allowed newer pending workflows to replace earlier pending deploy/proof runs;
2. Queue activation acquired the production lock before confirming successful application deployment;
3. scheduled trusted fresh provisioning could contend before exact-SHA deploy evidence;
4. the ephemeral proof Worker initially hit Cloudflare 1042 during same-zone Worker fetch;
5. the IC2 proof initially entered the shared production queue before the normal post-deploy regression chain had drained.

The deployment/activation guards were hardened, the redundant same-zone anonymous fetch was removed, and the successful attempt ran only after the exact-SHA production regression queue had completed. No gate, isolation rule or latency threshold was weakened to obtain green evidence.
