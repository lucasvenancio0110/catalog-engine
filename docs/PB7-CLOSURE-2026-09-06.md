## Merchant-safe progress contract

The customer-facing projection uses named stages backed by durable state:

```text
preparing
-> discovering
-> importing
-> finalizing
-> organizing
-> checking
-> ready
```

Retry is projected only when the backend has a real durable automatic retry scheduled. Transient portal refresh failures preserve the last confirmed useful state rather than fabricating an empty/reset state.
